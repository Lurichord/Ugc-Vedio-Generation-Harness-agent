# 新运行时：第一圈

当前只实现这一圈 loop。任务图、参考图、Seedance、调度都不在这一圈里。下一圈再往同一个 loop 上加一个工具。

## 这一圈做什么

调用方准备好 `messages` 和一个工具表。`run_loop` 重复下面的事，直到模型不再选工具，或步数用尽：

1. 调用 `decide(messages, tool_names)`，得到一步。
2. 把这一步追加为 `assistant` 消息。
3. `tool` 为空：循环结束，原因是 `done`。
4. `tool` 有名字：执行工具表里的函数，把结果追加为下一条 `user` 消息，回到第 1 步。
5. 步数到达 `max_steps` 仍没有空工具：循环结束，原因是 `budget`。

```python
class Step(BaseModel):
    tool: str | None = None
    arguments: dict = {}
    message: str = ""

def run_loop(
    messages: list[dict],
    *,
    decide: Callable[[list[dict], list[str]], Step],
    tools: dict[str, Callable[[dict], dict]],
    max_steps: int = 8,
) -> LoopResult: ...
```

`LoopResult` 含三字段：`messages`、`steps`、`stop`（`done` 或 `budget`）。传入的 `messages` 不修改，返回的是新列表。

## 消息

`assistant` 的 `content` 是这一步的 JSON：

```json
{"tool": "echo", "arguments": {"text": "hi"}, "message": ""}
```

工具结果追加为 `user`：

```json
{"tool": "echo", "result": {"text": "hi"}}
```

工具不在表里，或函数抛出异常：循环不中断。`result` 为 `{"ok": false, "error": "..."}`，错误文本截断到 500 字。模型下一步仍能看见这条失败。

`tool` 为 `null` 或去掉空白后为空，都算结束。结束的那一步仍然写入 `assistant`，不再追加工具结果。

`decide` 收到的 `tool_names` 是工具表键名的排序列表。这一圈的工具表由调用方传入。测试里只用一个 `echo`。生产工具一个都不注册。

## 测试

| 测试 | 断言 |
|---|---|
| `test_echo_then_stop` | 假 `decide` 第一次调用 `echo`，第二次 `tool` 为空。`echo` 只被调用一次。`stop == done`。结果消息里能看到 `echo` 的返回值 |
| `test_unknown_tool_continues` | 工具名不在表里。下一条 `user` 的 `result.ok` 为 false，`error` 含 `unknown_tool`。随后模型结束，循环不抛异常 |
| `test_tool_error_continues` | 工具抛 `RuntimeError`。下一条结果的 `error` 含异常文本。模型再结束 |
| `test_budget` | `max_steps=1`，模型一直调用 `echo`。工具只调用一次，`stop == budget` |
