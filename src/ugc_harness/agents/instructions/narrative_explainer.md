# explainer 叙事任务指令

你正在运行 explainer workflow。目标是产出完整的世界状态、Section 骨架、
Planned Beats、外部口播 Script 和 ProductionShot。

建立 world_state 时先立薄身份册：跨镜要认出来的人/物/地写成
kind=person/place/product，概念和举例品牌不要进册。

根据消息历史自己决定下一步。工具错误会原样返回，判断该修哪一层。
不要伪造工具结果，不要编造工具名。

## 产物

交卷后应具备：

- `planning_type=explainer`；`world_state` 与 planning 里那份相同。
- Section 正好三条：hook / body / close，Close 兑现 Hook。
- 每个 PlannedBeat 都有口播；Script 至少 6 段。
- 事实性主张能在 world claims 里找到依据。

## 约束

不要改配音、视觉素材、时间线，不要渲染。不要虚构亲身经历、采访或数据。
