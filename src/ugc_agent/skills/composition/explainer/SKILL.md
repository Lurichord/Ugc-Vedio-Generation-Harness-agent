# 科普

这是不出镜的讲解/教学片，画面服务于把概念讲清楚。不是数字人口播，也不是剧情短剧。用户没说清片种时先问，不要写大纲。用户要固定数字人形象出镜时，改用 `avatar-explainer`。选定后先 `read_project`，再严格按顺序执行。前置步骤未写入项目状态前，禁止跳步。

事实写入项目状态，不要另存 `input.json` / `plan.json` / `shot.json`。生成工具返回的路径立刻 `record_media`。

核心原则：
- 不能只把主题或原文直接塞进视频 prompt，要先形成可讲解的结构和口播
- 同一概念的主体、场景、图示、文字样式在不同片段必须保持一致
- 分段画面必须连续，不能每段都像独立新视频
- **先做完全部分段口播和时间戳，再出画**；不要用上一段视频的分离音频驱动下一段口播
- 要锁图示/四宫格或本镜有口播时用 `ref2va`；只要从上一镜尾帧强制接着演、且不需要参考图和音频时用 `fl2va`

## 依赖工具

- `read_project` / `save_outline` / `save_story` / `save_shot_design` / `record_media` / `set_deliverable`
- `load_skill seedance-prompt`：写镜头 `prompt`、调用 `video-gen` 前加载
- `vision-understanding`：理解参考图/视频，检查生成结果
- `extract-video-frame`：从参考视频或上一段抽关键帧、尾帧
- `image-gen`：图示、场景、主体、文字样式和四宫格教学帧
- `text-to-speech`：分段讲解口播和时间戳；**视频生成前必须全部完成**
- `video-gen`：活动画面。有口播或要锁四宫格/图示时用 `ref2va` 并传入**当前段**口播和该段四宫格；只要画面从上一镜尾帧强制连贯、且不需要参考图和音频时用 `fl2va`
- `merge-video`：按讲解顺序合并

## 写入项目状态

`save_outline` 只写硬指标：主题、片种 `explainer`、受众、画面形态、投放。分辨率、字幕、配音、BGM 写进 `visual_form`。不要把长段讲解写进大纲。

`save_story` 写完整讲解稿。正文开头列出要覆盖的知识点，再写口播。用户已给旁白则优先使用；没有则按主题和受众补足。

`save_shot_design` 才是分段执行表。图示/道具挂道具，场景挂场景，需要出镜的示例人物才挂人物。写 `prompt` 前先 `load_skill seedance-prompt`。`prompt` 是交给 `video-gen` 的画面正文：主体、场景、动作、运镜、分时段、风格。教学点写进画面动作里。有口播时以将传入的 `[音频1]` 为准，不要另编一套词。镜头类型（`连续镜头` / `回锚镜头`）写在开头一行。不要把四宫格 id、音频文件名写进 prompt。

媒体 `owner_ref` 形如 `prop:p1` / `place:loc1` / `character:c1` / `shot:shot_01` / `project`。镜头完成看该镜是否已挂上四宫格、口播音频和需要的视频。

## 工作流

### 步骤0：锁定账本

`read_project`。后续文件都走工具路径和 `record_media`。

### 步骤1：输入与讲解需求

不要跳步。只整理输入，不直接写视频 prompt。

1. 读取主题说明、要讲清楚的知识点、参考文本、教学目标、参考图片、参考视频、参考音频。
2. 提取：要解释的概念/主张/流程；受众已知什么；时长、分辨率、画幅、风格、字幕、配音；必须出现的画面或例证。
3. 对参考图片、参考视频调用 `vision-understanding`，提取主体、外观、使用场景、风格。
4. `save_outline`。

### 步骤2：讲解稿

前置检查：大纲已写入。

`save_story`。按开场问题、展开说明、例证或对比、收尾收获来写。尽量每个镜头都有对应旁白。参考文本或需求较单薄时，在不改变核心结论的前提下，从台词、图示动作、场景细节上补内容，避免片段空泛或重复。

### 步骤3：教学分镜

前置检查：讲解稿已写入。注意分镜内容的丰富度。

根据总时长和讲解结构拆片段。每个片段不超过 `video-gen` 最大时长。不要切得太碎，优先让每段承载一个清晰教学点。常见结构：

- 导入问题和主题
- 逐点讲解
- 例证或意象展开
- 对比或深化
- 总结回顾

`save_shot_design`。区分口播段和画面段：口播段的画面正文要能跟上这段要说的话，画面段写清示意图、对比或例证。每个片段写清目标时长、场景、需要出现的主体/图示/文字、一致性资产、镜头类型；`prompt` 按 `seedance-prompt` 写。

分镜节奏应符合教学推进，不要写成无关联画面堆砌。

### 步骤4：图示与场景资产

前置检查：故事和镜头设计已写入。

1. 先做资产覆盖诊断：对照输入和镜头设计，判断现有参考是否足够支撑每个教学片段。
2. 提取反复出现或关键的元素并补齐：
   - 风格锚图：`image-gen` 必须参考用户参考图的风格
   - 角色：仅当讲解需要示例人物时才生成统一三视图，纯白背景；有人物参考则跟参考图，没有则跟参考风格
   - 场景：多核心场景分别出图
   - 图示/道具：干净背景，高频解释性道具优先，可在一张图里放多个
   - 板书或关键词文字样式
3. `record_media` 挂到对应人物、道具、场景。参考素材较少时要主动补齐，不要空着进入四宫格。

### 步骤5：分段四宫格教学帧

前置检查：必要一致性资产已挂上。未完成立刻返回步骤4。每个镜头都要有对应四宫格。

1. 为每个讲解片段生成一张四宫格，展示该段整体画面走向，不是最终视频。
2. Prompt 写明：生成一张4宫格图片，从左上到右下分别是1-4，每个格子要有数字和简短文本。参考[图1][图2][图3]的一致性资产；非首段参考[图4]上一段四宫格，强调衔接上一张第4格继续，避免内容重复。然后写上本段讲解内容和每格主要内容。
3. 传入当前段相关一致性资产、原始参考图或参考视频关键帧、上一段四宫格（首段除外）。
4. `record_media` 挂到对应镜头，作为该段 `video-gen` 的核心视觉参考。

### 步骤6：音频与时间戳

前置检查：每个片段的四宫格已生成。**未完成整套分段口播，不得进入视频生成。**

1. 按镜头调用 `text-to-speech`，全片锁定同一音色、语速、音高、音量。
2. 每段口播 `record_media` 挂到对应镜头；有时间戳一并挂上。
3. 字幕只能基于时间戳生成，禁止手写估时字幕。
4. 不要用 `split-audio` 从上一段视频抽音频当本段口播。纯口播加配图的镜头可以不出活动视频，但仍要先有这段音频。

### 步骤7：分段画面

前置检查：每个需要出画的镜头，若走 `ref2va` 则已挂上四宫格和当前段口播。每段生成前重新 `read_project`。先选 `mode`，再调用 `video-gen`。

两种模式：

- `fl2va`：只把上一镜尾帧当首帧。不传四宫格、不传一致性资产、不传 `audio_paths`。用于本镜只要画面从上一镜结尾强制连贯下去，并且不需要锁参考图、也不需要本段口播。
- `ref2va`：锁教学画面。传入当前段四宫格、相关一致性资产、需要的原始参考，**必须传当前段旁白**。若是 `连续镜头`，还必须把上一镜尾帧放进 `reference_paths`，prompt 写成作为首帧。用于本镜有口播、要跟四宫格讲清概念，或 `回锚镜头`。

怎么选：本镜有口播或要锁四宫格/图示 → `ref2va`。本镜不要参考图、不要音频、只要接着上一镜画面演 → `fl2va`。首镜没有上一镜尾帧，不能用 `fl2va`。

先看本镜相对上一镜是不是连续。只有 `连续镜头` 才抽尾帧、对照上一镜 prompt 看停在哪、再微调本镜 prompt。`回锚镜头` 跳过这三步，直接用本镜分镜里的 prompt 出画。

`连续镜头` 且走 `ref2va` 时，生成前必须先看尾帧，再微调旧 prompt：

1. 对上一镜成片 `extract-video-frame` 抽尾帧。
2. 把上一镜实际用来生成视频的 prompt 和这张尾帧一起交给 `vision-understanding`，对照提示词看最后一幕停在了哪：主体在画面哪、朝向、景别、手势或图示停在哪、背景怎么切、空间关系、光线从哪来。
3. 拿本镜分镜里的旧 prompt 来微调，不要另起一套：补上从哪个画面接上、四宫格怎么往下演、如何不和尾帧打架。`reference_paths` 先放上一镜尾帧，再放四宫格和一致性资产；prompt 里写成[图1]作为首帧，其余参考按实际传入顺序接着编号。
4. 再调用 `video-gen`，使用微调后的 prompt，把尾帧和本镜资产一起传入。

`回锚镜头` 不要抽上一镜尾帧，也不要对照尾帧改 prompt。回到原始风格/场景/图示锚图和当前段四宫格，不带上一段视频，直接用本镜分镜里的 prompt 调用 `video-gen`。

`fl2va` 只传那一张尾帧，prompt 写从这张图接着怎么动即可。

共通：

- 禁止把全部历史视频塞给当前段
- `ref2va` 的 prompt 按实际传入顺序从[图1]编号；参考图有关系时写明，例如[图1]提供风格，[图2]提供场景，[图3]提供图示文字样式
- `ref2va` 写出这个镜头的完整旁白，但音频以传入的当前段口播为准，不要另编一套词

单段超时设得足够长。每段生成后抽尾帧并挂上。`vision-understanding` 检查概念是否讲清、图示是否正确；不合格重生。通过后 `record_media`。

### 步骤8：合并与验收

前置检查：全部需要生成的片段都已完成。有缺失立刻返回上一步。

1. `merge-video` 按讲解顺序合并。
2. 根据用户需求整理字幕、关键词文字、音效和背景音乐；字幕只能来自时间戳。
3. `set_deliverable`。
4. 最终检查：成片存在、讲解覆盖大纲承诺的知识点、主体和图示一致、旁白连续、时长符合大纲。缺文件或检查不过，不得对用户说已经做完。

## 硬规则

1. 讲解理解是核心：不能只把主题或原文塞进视频 prompt。
2. 资产一致性是核心：同一主体、场景、道具、文字样式必须保持一致。
3. 每个教学片段先有四宫格，再配音，再出画。
4. 有口播的镜头必须 `ref2va`，只传当前段口播，不用上一段视频音频驱动下一段。`fl2va` 不传音频、不传参考图，只传上一镜尾帧。前后两镜连续时，生成前必须对照上一镜生成 prompt 看尾帧停在哪，微调本镜旧 prompt 后再生成；`reference_paths` 必须带上上一镜尾帧，并写成作为首帧。`回锚镜头` 不看上一镜尾帧，也不传上一镜尾帧。
5. 这不是数字人讲解技能。用户要固定数字人形象出镜时，改用 `avatar-explainer`。
6. 成片必须 `set_deliverable`。
