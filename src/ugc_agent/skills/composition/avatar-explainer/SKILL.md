# 数字人讲解

这是数字人口播，不是演绎、不是广告堆卖点、也不是不出镜的科普动画。用户没说清片种时先问，不要写大纲。选定后先 `read_project`，再严格按顺序执行。前置步骤未写入项目状态前，禁止跳步。

事实写入项目状态，不要另存 `input.json` / `requirements.json` / `story_script.json` / `plan.json` / `asset.json` / `shot.json`。生成工具返回的路径立刻 `record_media`。

核心链路：
1. 整理输入与口播主线
2. 提取硬指标
3. 规范化口播稿
4. 规划分段、连续/回锚、音频和字幕
5. 建立人物/背景锚图
6. 拆成逐段执行表
7. **先做完全部分段口播和时间戳**
8. 再逐段生成数字人视频
9. 合成、烧录字幕、登记成片

本片种禁止用 `split-audio` 从上一段视频抽音色来驱动下一段。口播连续性靠全片锁定的 `text-to-speech` 参数。画面要锁人物/背景时用 `ref2va`；只要从上一镜尾帧强制接着演、且本镜不需要参考图和音频时用 `fl2va`。

## 依赖工具

- `read_project` / `save_outline` / `save_story` / `save_shot_design` / `record_media` / `set_deliverable`
- `load_skill seedance-prompt`：写镜头 `prompt`、调用 `video-gen` 前加载
- `vision-understanding`：理解参考视频人物、服装、姿态、背景、说话状态，并检查生成结果
- `extract-video-frame`：从参考视频抽 3-5 帧人物帧，从分段视频抽尾帧
- `image-gen`：人物主锚图、单张三视图、演播背景
- `text-to-speech`：分段口播和时间戳；视频生成前必须全部完成
- `video-gen`：逐段出画。有口播或要锁人物/背景时用 `ref2va` 并传入**当前段**口播；只要画面从上一镜尾帧强制连贯、且不需要参考图和音频时用 `fl2va`
- `merge-video`：按镜头顺序拼接成片

## 写入项目状态

`save_outline` 只写硬指标：主题、片种 `avatar-explainer`、受众、画面形态、投放（时长、画幅、语言、平台）。分辨率、fps、数字人出镜、演播背景、语速语气、字幕、BGM、输出文件名写进 `visual_form`，不要在这里写剧情或分段。

`save_story` 写规范化后的完整口播。覆盖点、口播主线选择理由、是否扩写，写在正文开头的制作备注里，然后接 `final_script`。

`save_shot_design` 才是分段执行表。人物挂数字人锚点，背景挂演播场景，产品参考挂道具。写 `prompt` 前先 `load_skill seedance-prompt`。`prompt` 是交给 `video-gen` 的画面正文：主体、场景、动作、运镜、分时段、风格。有口播时以将传入的 `[音频1]` 为准，不要另编台词。必须能看出覆盖点和 `连续镜头` / `回锚镜头`（镜头类型写在开头一行）。不要把音频文件名、时间戳路径写进 prompt。

媒体 `owner_ref` 形如 `character:c1` / `place:loc1` / `prop:p1` / `shot:shot_01` / `project`。镜头是否完成看该镜是否已挂上**口播音频和视频**，不要口头说完成。

## 工作流

### 步骤0：锁定账本

`read_project`。后续所有图片、音频、视频都用工具返回路径，立刻 `record_media`。不要手建目录，不要另存 json。

### 步骤1：整理输入

只整理输入，不拆镜头，不直接写视频 prompt。

1. 读取需求、参考文本、参考视频、参考音频、参考图片。
2. 有参考视频时必须先 `vision-understanding`，记录人物、服装、姿态、背景和说话状态。
3. 口播主线不要混写：
   - 用户明确说“以参考文本为准”或“参考文本就可以”时，使用参考文本
   - 否则若需求中有完整口播文案，优先使用需求口播
   - 两者冲突时选一条，把冲突和选择理由写入故事备注
4. 调用 `save_outline`。

### 步骤2：硬指标

前置检查：大纲已写入。

只提取硬指标：时长、分辨率、比例、fps、数字人出镜、演播背景、语速语气、字幕、BGM、输出文件名。不要在这里写剧情或分段。缺的字段写「没有」。用 `save_outline` 更新。

### 步骤3：口播稿

前置检查：硬指标已写入。必须 `save_story`。

默认只做规范化文案：清理重复、补标点、统一口语节奏、按语义分段、提取覆盖点。保留参考文本的核心信息、顺序和结论。

只有文本明显不足以支撑目标时长、缺少必要承接，或无法支撑每个镜头的台词时，才做轻量扩写。扩写不得改变主题、立场和核心结论。语速大约 180-220 字/分钟；无明确时长时默认写约 180-220 字。

### 步骤4：整体计划

前置检查：口播稿已写入。

`save_shot_design` 先把风格、人物、场景和镜头骨架写上。必须能看出总分段数，并规划：

- 音频分段
- 字幕是否做、如何跟时间戳走
- BGM
- 人物连续性
- 背景一致性
- `连续镜头` / `回锚镜头`

每段建议 4-10 秒，围绕一个信息点、卖点或过渡目标，避免多镜重复同一句，也避免单镜塞太多无关信息。

### 步骤5：稳定资产

前置检查：镜头骨架已写入。

1. 有参考视频时，`extract-video-frame` 提取 3-5 帧人物帧，`record_media` 挂到人物。
2. `image-gen` 生成人物主锚图，后续当作 `avatar_primary`。基于参考帧只换安全/干净背景，不改变身份、发型、五官、服装、比例和视觉风格。
3. `image-gen` 再生成单张三视图，挂到同一人物。
4. 需要演播背景时生成背景主锚图，挂到场景。
5. 有产品参考图时再补产品锚图，挂到道具。
6. 不要为每个镜头单独做一套脸和背景。

### 步骤6：逐段执行表

前置检查：人物主锚图和三视图已挂上。

补全每个镜头：`prompt` 按 `seedance-prompt` 写好画面正文，必须能看出台词对应的口播、覆盖点、镜头类型。校验：

- 所有覆盖点都有对应镜头
- 每个镜头都有台词
- 总时长与大纲基本一致
- 镜头类型只有 `连续镜头` 或 `回锚镜头`
- 尚未生成的镜头不要标完成

用 `save_shot_design` 整层替换。未完成这一步，禁止生成音频和视频。

### 步骤7：音频与时间戳

前置检查：执行表已保存。**未完成整套分段口播，不得进入视频生成。**

1. 按镜头顺序调用 `text-to-speech`，每段一句/一段口播。
2. 全片锁定同一套音色、语速、音高、音量，不要中途换声。
3. 每段口播 `record_media` 挂到对应镜头；若工具返回时间戳文件，一并挂上。
4. 全部段完成后，可再生成一条完整口播挂到 `project`。
5. 字幕只能基于时间戳生成，禁止手写估时字幕。没有时间戳就先不做字幕。

### 步骤8：逐段视频

前置检查：每个有口播的镜头都已挂上当前段音频。每段生成前重新 `read_project`。先选 `mode`，再调用 `video-gen`。

两种模式：

- `fl2va`：只把上一镜尾帧当首帧。不传人物锚图、不传背景图、不传 `audio_paths`，声音由模型自己出。用于本镜只要画面从上一镜结尾强制连贯下去，并且不需要锁参考图、也不需要本段口播。
- `ref2va`：锁数字人形象和口型。传入人物主锚图/三视图，需要时加背景锚图，**必须传当前段口播**。若是 `连续镜头`，还必须把上一镜尾帧放进 `reference_paths`，prompt 写成作为首帧。用于本镜有台词、要认人、要跟口播，或 `回锚镜头`。

怎么选：本镜有口播或要锁人物/背景 → `ref2va`。本镜不要参考图、不要音频、只要接着上一镜画面演 → `fl2va`。首镜没有上一镜尾帧，不能用 `fl2va`。

先看本镜相对上一镜是不是连续。只有 `连续镜头` 才抽尾帧、对照上一镜 prompt 看停在哪、再微调本镜 prompt。`回锚镜头` 跳过这三步，直接用本镜分镜里的 prompt 出画。

`连续镜头` 且走 `ref2va` 时，生成前必须先看尾帧，再微调旧 prompt：

1. 对上一镜成片 `extract-video-frame` 抽尾帧。
2. 把上一镜实际用来生成视频的 prompt 和这张尾帧一起交给 `vision-understanding`，对照提示词看最后一幕停在了哪：人物在画面哪、朝向、景别、手势停在哪、背景怎么切、空间关系、光线从哪来。
3. 拿本镜分镜里的旧 prompt 来微调，不要另起一套：补上从哪个姿态/机位接上、镜头怎么走、如何不和尾帧打架。`reference_paths` 先放上一镜尾帧，再放人物/背景锚图；prompt 里写成[图1]作为首帧，其余参考按实际传入顺序接着编号。
4. 再调用 `video-gen`，使用微调后的 prompt，把尾帧和本镜资产一起传入。

`回锚镜头` 不要抽上一镜尾帧，也不要对照尾帧改 prompt。回到原始人物锚图和背景锚图，不带上一段视频，直接用本镜分镜里的 prompt 调用 `video-gen`。

`fl2va` 只传那一张尾帧，prompt 写从这张图接着怎么动即可。

共通：

- 禁止把全部历史视频塞给当前段
- 禁止把上一段视频的分离音频当作本段口播
- `ref2va` 的 prompt 必须写明「参考图中的人物形象作为数字人口播讲解人」
- 参考图按实际传入顺序写成[图1][图2]……，不要引用未传入的图
- 禁止默认写「现实风格」，必须跟人物锚图的视觉风格

每段 `video-gen` 后 `extract-video-frame` 抽尾帧，`record_media` 挂到该镜头，留给下一镜选模式或改 prompt。不合格用 `vision-understanding` 检查后重做当前段，不跳过。

### 步骤9：合成与验收

前置检查：全部镜头都已挂上视频和对应口播。

1. `merge-video` 按镜头顺序拼接。
2. 按需叠 BGM；若需求要求字幕，只根据时间戳生成字幕并合成进成片。
3. `set_deliverable` 登记成片。
4. 最终检查：成片存在、时长符合大纲、人物一致、口播覆盖完整、字幕没有手写估时。缺文件或检查不过，不得对用户说已经做完。

## 硬规则

1. 未写大纲前不写口播，未写口播前不拆镜头，未挂锚图前不生成音频，未完成整套分段音频前不生成视频。
2. 有口播的镜头必须 `ref2va`，只传当前段口播，不用上一段视频音频驱动下一段。`fl2va` 不传音频、不传参考图，只传上一镜尾帧。
3. 前后两镜连续时，生成前必须对照上一镜生成 prompt 看尾帧停在哪，微调本镜旧 prompt 后再生成；`reference_paths` 必须带上上一镜尾帧，并写成作为首帧。`回锚镜头` 回到原始人物和背景，不看上一镜尾帧，不传上一镜尾帧，不带上一段视频。
4. 不得把全部历史视频传给当前段。
5. 字幕若被要求，必须来自时间戳。
6. 成片必须 `set_deliverable`。
