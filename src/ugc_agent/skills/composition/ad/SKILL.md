# 广告

这是卖点驱动的产品/品牌广告，不是数字人口播，也不是剧情短剧。用户没说清片种时先问，不要写大纲。选定后先 `read_project`，再严格按顺序执行。前置步骤未写入项目状态前，禁止跳步。

事实写入项目状态，不要另存 `input.json` / `plan.json` / `shot.json`。生成工具返回的路径立刻 `record_media`。

核心逻辑：先有完整广告故事，再拆镜头。所有环节以文本卖点为绝对核心，通过连贯叙事串联卖点，避免素材堆砌和无意义炫技。

```
理解需求 → 盘点资产 → 提取卖点 → 构建叙事 → 规划镜头 → 补齐产品/风格资产 → 先配完全部分段旁白 → 再逐镜头出画 → 合成校验
```

本片种不要用上一段视频的 `split-audio` 当本段口播。旁白全片先用 `text-to-speech` 按段做好。要锁产品和风格、或本镜有旁白时用 `ref2va`；只要从上一镜尾帧强制接着拍、且不需要参考图和音频时用 `fl2va`。

## 依赖工具

- `read_project` / `save_outline` / `save_story` / `save_shot_design` / `record_media` / `set_deliverable`
- `load_skill seedance-prompt`：写镜头 `prompt`、调用 `video-gen` 前加载
- `vision-understanding`：识别产品截图、检查镜头和成片
- `image-gen`：产品三视图、风格参考、必要时的标注图
- `text-to-speech`：分段旁白和时间戳；**视频生成前必须全部完成**
- `video-gen`：逐镜头出画。有旁白或要锁产品/风格时用 `ref2va` 并传入**当前段**旁白；只要画面从上一镜尾帧强制连贯、且不需要参考图和音频时用 `fl2va`
- `extract-video-frame`：连续镜头需要时抽尾帧
- `merge-video`：按镜头顺序拼接，需要时加过渡

## 写入项目状态

`save_outline` 只写硬指标：主题、片种 `ad`、受众、画面形态、投放。分辨率、风格、配音、字幕、BGM 写进 `visual_form`。不要把卖点清单或分镜写进大纲。

`save_story` 写完整广告旁白稿。正文开头先列按优先级排序的卖点清单，再写连贯旁白。卖点必须全部来自用户需求或参考文本，不得编造。

`save_shot_design` 才是镜头执行表。产品挂道具，风格/场景挂场景。每个镜头必须能看出对应哪个卖点。写 `prompt` 前先 `load_skill seedance-prompt`。`prompt` 是交给 `video-gen` 的画面正文：主体、场景、动作、运镜、分时段、音效、风格。有旁白时以将传入的 `[音频1]` 为准，不要另编一套词。镜头类型（`连续镜头` / `切分镜头`）写在开头一行。卖点写进画面动作里，不要把音频文件名写进 prompt。

媒体 `owner_ref` 形如 `prop:p1` / `place:loc1` / `shot:shot_01` / `project`。镜头完成看该镜是否已挂上旁白音频和视频。

## 工作流

### 步骤0：锁定账本

`read_project`。后续文件都走工具路径和 `record_media`。

### 步骤1：需求与资产盘点

不要跳步。

1. 提取时长、分辨率、风格、配音、核心期望效果。
2. 收集产品功能描述和参考文本，这是后续唯一卖点来源。
3. 盘点用户给的参考图、视频、音频。有图有视频时先 `vision-understanding`。
4. `save_outline`。输出确认清单：核心卖点数量、预计镜头数、总时长范围。品牌宣传默认按一条连续广告规划，不要做成多个独立短广告。

### 步骤2：卖点结构化

前置检查：大纲已写入。

1. 从参考文本和需求中提取核心卖点，按优先级排序。用户明确提到的卖点必须全部提取，无遗漏。
2. 有限尊重用户参考文本里的展示逻辑。
3. 先在内部想清楚整支广告要讲什么故事，再拆画面，不要把卖点直接映射成互不相关的镜头。
4. `save_story` 写成连贯旁白完整稿：
   - 开场：一句话引入产品，抓注意力
   - 核心展示：用户痛点 → 产品解决方案 → 功能优势 → 使用效果，卖点之间加过渡
   - 结尾：总结核心优势，行动号召或品牌展示
5. 除非用户明确要求无旁白，默认规划完整旁白主线。

### 步骤3：三段式镜头规划

前置检查：故事已写入。尽量遵循 1 分钟广告节奏，用户另有时长时按比例缩放：

| 剧情阶段 | 时长占比 | 内容要求 | 镜头类型 |
|---|---|---|---|
| 开场抓眼球 | 15% | 产品核心外观或最震撼的 P0 卖点 | 切分镜头（全景/特写快速切换） |
| 核心卖点展示 | 70% | 按优先级逐一展示，每个卖点至少 1 个独立镜头 | 连续或切分 |
| 结尾收尾 | 15% | 品牌、slogan 或使用场景总结 | 切分镜头（全景收尾） |

1. 基于连贯叙事文案拆镜头，每个镜头对应叙事中的一个片段，必须承接上一镜结尾、开启当前内容，禁止孤立描述。
2. 每个镜头规划时长（通常 4-15 秒）、旁白、字幕、高亮标注、镜头类型、关联资产。
3. `save_shot_design`。前置校验：所有卖点都有对应镜头、总时长约 ±5 秒、三段式完整、前后逻辑连贯。

### 步骤4：产品与风格资产

前置检查：镜头设计已写入。

1. `vision-understanding` 对照镜头评估用户素材是否足够。
2. 必须生成全局一致性资产：
   - 产品统一参考图：基于用户素材用 `image-gen` 生成标准产品三视图；多个产品就各出一套
   - 风格参考图：色调、光影、质感、标注样式；不要出现具体文字，仅作风格参考
3. `record_media` 挂到对应道具或场景。不要为每个镜头单独做一套产品外观。

### 步骤5：补全执行表

前置检查：产品三视图和风格参考已挂上。

每个镜头按 `seedance-prompt` 补全画面正文，必须能看出旁白对应关系、卖点和镜头类型。`save_shot_design`。未完成禁止配音和出画。

### 步骤6：音频与时间戳

前置检查：执行表已保存。**未完成整套分段旁白，不得进入视频生成。**

1. 按镜头调用 `text-to-speech`，每段旁白单独出音频。
2. 全片锁定同一套音色、语速、音高、音量。
3. `record_media` 挂到对应镜头；有时间戳一并挂上。
4. 字幕只能基于时间戳，禁止手写估时字幕。
5. 不要用 `split-audio` 从上一段成片抽音频来当本段旁白。

### 步骤7：逐镜头视频

前置检查：每个有旁白的镜头都已挂上当前段音频。每段生成前重新 `read_project`，复述卖点列表和镜头设计。先选 `mode`，再调用 `video-gen`。

两种模式：

- `fl2va`：只把上一镜尾帧当首帧。不传产品图、不传风格图、不传 `audio_paths`。用于本镜只要画面从上一镜结尾强制连贯下去，并且不需要锁参考图、也不需要本段旁白。
- `ref2va`：锁产品和风格。传入全局产品/风格参考，**必须传当前段旁白**。若是 `连续镜头`，还必须把上一镜尾帧放进 `reference_paths`，prompt 写成作为首帧。用于本镜有旁白、要认产品、要跟卖点画面，或 `切分镜头`。

怎么选：本镜有旁白或要锁产品/风格 → `ref2va`。本镜不要参考图、不要音频、只要接着上一镜画面拍 → `fl2va`。首镜没有上一镜尾帧，不能用 `fl2va`。

先看本镜相对上一镜是不是连续。只有 `连续镜头` 才抽尾帧、对照上一镜 prompt 看停在哪、再微调本镜 prompt。`切分镜头` 跳过这三步，直接用本镜分镜里的 prompt 出画。

`连续镜头` 且走 `ref2va` 时，生成前必须先看尾帧，再微调旧 prompt：

1. 对上一镜成片 `extract-video-frame` 抽尾帧。
2. 把上一镜实际用来生成视频的 prompt 和这张尾帧一起交给 `vision-understanding`，对照提示词看最后一幕停在了哪：产品/人物在画面哪、朝向、景别、手势或标注停在哪、背景怎么切、空间关系、光线从哪来。
3. 拿本镜分镜里的旧 prompt 来微调，不要另起一套：补上从哪个角度/位置接上、镜头怎么走、如何不和尾帧打架。`reference_paths` 先放上一镜尾帧，再放产品/风格资产；prompt 里写成[图1]作为首帧，其余参考按实际传入顺序接着编号。
4. 再调用 `video-gen`，使用微调后的 prompt，把尾帧和本镜资产一起传入。

`切分镜头` 不要抽上一镜尾帧，也不要对照尾帧改 prompt。不带上一段视频，只使用当前段产品和风格资产，直接用本镜分镜里的 prompt 调用 `video-gen`。

`fl2va` 只传那一张尾帧，prompt 写从这张图接着怎么动即可。

共通：

- 若包含台词：`ref2va` 的 prompt 里写清说话人属性、音色、台词
- 若要求展示文案：prompt 里写清文案内容和展现形式
- 禁止把全部历史视频塞给当前段
- 参考图按实际传入顺序写成[图1][图2]……

每段生成后 `extract-video-frame` 抽尾帧并挂到该镜头。`vision-understanding` 检查是否符合描述和对应卖点；不合格重做当前段。通过后挂视频到该镜头。

### 步骤8：合成与验收

前置检查：全部镜头已挂上视频和旁白。

1. 逐条核对故事里的卖点是否都有视觉呈现。
2. `merge-video` 按顺序拼接，需要时加过渡。
3. 对成片再做一次 `vision-understanding`；不合格定位段落返工。
4. `set_deliverable`。缺文件、卖点没覆盖或检查不过，不得对用户说已经做完。

## 硬规则

1. 卖点 100% 覆盖，产品/场景/风格高度一致。
2. 先讲完整广告故事，再拆镜头，禁止把卖点堆成互不相关的画面。
3. 品牌宣传默认按连续视频规划，不要做成多个独立短广告。
4. 有旁白的镜头必须 `ref2va`，只传当前段旁白，不用上一段视频音频驱动下一段。`fl2va` 不传音频、不传参考图，只传上一镜尾帧。前后两镜连续时，生成前必须对照上一镜生成 prompt 看尾帧停在哪，微调本镜旧 prompt 后再生成；`reference_paths` 必须带上上一镜尾帧，并写成作为首帧。`切分镜头` 不看上一镜尾帧，也不传上一镜尾帧。
5. 不得为了补字段而编造用户没给的卖点或参考素材。
6. 成片必须 `set_deliverable`。
