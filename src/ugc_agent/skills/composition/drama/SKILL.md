# 演绎

先问清片子类型。用户没说清是数字人讲解、演绎、广告还是科普时，先问，不要写大纲。这是剧情片：先有完整故事和一致性资产，再逐段出画；跨段音色和 BGM 靠上一段成片的参考音频，而不是先配完全片口播。选定后先 `read_project`，再严格按顺序执行。前置步骤未写入项目状态前，禁止跳步。

事实写入项目状态，不要另存 `plan.json` / `shot.json`。生成工具返回的路径立刻 `record_media`。

核心原则：
- 先有完整故事，再拆镜头
- 角色、场景、道具、风格全片保持一致
- 每个片段时长拉满，不要切得太碎
- 生成是无状态的，要锁人设/场景/音色时必须显式传入参考图和参考音频
- **走 `ref2va` 时，第 n+1 段必须使用第 n 段拆出的音频作参考**
- 只要画面从上一镜尾帧强制连贯、且本镜不需要参考图和音频时，用 `fl2va`

## 依赖工具

- `read_project` / `save_outline` / `save_story` / `save_shot_design` / `record_media` / `set_deliverable`
- `load_skill seedance-prompt`：写镜头 `prompt`、调用 `video-gen` 前加载
- `vision-understanding`：理解参考素材和生成结果
- `image-gen`：角色三视图、场景图、道具图
- `video-gen`：逐段出画。要锁角色/场景/道具或跟上一段音色时用 `ref2va`（从第二段起带上一段参考音频；连续镜头还要把上一镜尾帧放进 `reference_paths`）；只要画面从上一镜尾帧强制连贯、且不需要参考图和音频时用 `fl2va`
- `split-audio`：拆上一段成片音频，作为下一段的音色/BGM 参考
- `extract-video-frame`：必要时抽尾帧
- `merge-video`：合并成片

本片种不要先用 `text-to-speech` 做完全片旁白再驱动口型。对白写进视频 prompt，音频连续性靠 `split-audio`。

## 写入项目状态

`save_outline` 写主题、片种 `drama`、受众、画面形态、投放。只写硬性承诺，不写长段剧情。

`save_story` 写完整剧情和对白。只写情节和对白，不写人物外形和镜头语言。

`save_shot_design` 才是分镜。角色、场景、道具分别挂人物/场景/道具。写 `prompt` 前先 `load_skill seedance-prompt`。`prompt` 是交给 `video-gen` 的画面正文：主体、场景、动作、运镜、分时段、对白、音效、风格。对白格式 `主体A说了: "..."；主体B说了: "..."`。参考按本镜实际传入顺序写成 `[图1][视频1][音频1]`，每条写明用途。镜头类型（`连续镜头` / `切分镜头`）写在开头一行。`连续镜头` 接着上一镜往下演；`切分镜头` 换场或新开一场，不接上一镜尾帧。不要把音频文件名写进 prompt。

媒体 `owner_ref` 形如 `character:c1` / `prop:p1` / `place:loc1` / `shot:shot_01` / `project`。镜头完成看该镜是否已挂上视频。

## 工作流

### 步骤1：需求解析与确认

不要跳步。

1. 读取用户提供的剧本、故事大纲、分镜或一句剧情，提取剧情主线、关键情节、角色设定、场景设定。
2. 提取用户指定的时长、风格、画面比例、细节要求。`save_outline`：主题、投放、受众、片种 `drama`、画面形态。
3. 识别会在多个片段中重复出现的角色、场景、道具，后面要做成一致性资产。
4. 对剧情做有逻辑的扩写，包括具体对白、动作细节和事件过程。用户没给够情节时必须自己补全，不能直接拿一句主题去生成视频。
5. 有参考图或参考视频时，`vision-understanding` 提取主体、外观、场景和风格，后续资产必须参考这些，不要另起一套人设。

### 步骤2：故事与分镜规划

前置检查：大纲已写入，核心要素已提取。

1. `save_story`。故事是完整剧情正文。
2. 根据总时长和剧情结构拆片段。每个片段时长不能超过 `video-gen` 最大支持时长。不要切太细，4-5 个片段为佳，每段尽量拉满。
3. 片段分割必须是逻辑连贯的事件单元。例如女主角摔倒、男主角扶住，必须放在同一片段，不能拆到两个片段导致动作接不上。
4. 分镜节奏符合影视规律：开篇铺垫 → 情节发展 → 高潮冲突 → 结尾收束。
5. `save_shot_design`。每个镜头写清时长、场景、出场角色/物体、需要的一致性资产、相对上一镜是 `连续镜头` 还是 `切分镜头`；`prompt` 按 `seedance-prompt` 写成可直接给 `video-gen` 的正文，对白具体、细节充分，不能笼统。
6. 每个片段都要有说话内容，丰富、多样、不重复。默认走 `ref2va`；只有本镜明确只要画面强制连贯、且不需要参考图和音频时才用 `fl2va`。

### 步骤3：一致性资产图片

前置检查：故事和镜头设计已写入。未完成前禁止进入视频生成。

1. 提取镜头设计里反复出现的角色、核心场景、关键道具、风格设定。生成越多越好。
2. 角色：`image-gen` 生成统一三视图（正面、侧面、背面），纯白背景，一张图至多一个角色。可以生成主角、次要人物、配角。若用户给了人物参考图，必须参考该图，不得另造脸。
3. 场景：`image-gen` 生成场景设定图，图中不要出现角色。多场景就多张图。
4. 道具：干净背景，方便复用。高频道具优先。
5. 明确统一的风格描述词，应用到所有后续生成。提前规划统一音效和背景音乐气质。
6. `record_media` 把每张图挂到对应人物、道具、场景。不要为每个镜头单独做一套资产。

### 步骤4：分段生成视频

前置检查：必要一致性资产已挂上；未完成则立刻返回步骤3。每段生成前重新 `read_project`。先选 `mode`，再调用 `video-gen`。

两种模式：

- `fl2va`：只把上一镜尾帧当首帧。不传角色/场景/道具图、不传 `audio_paths`。用于本镜只要画面从上一镜结尾强制连贯下去，并且不需要锁参考图、也不需要上一段音频。
- `ref2va`：锁人设和剧情。传入本镜相关角色、场景、道具图。若是 `连续镜头`，还必须把上一镜尾帧放进 `reference_paths`，prompt 写成作为首帧。从第二段起还要带上一段 `split-audio`。用于本镜要演新情节、要认人，或要接上一段音色/BGM。

怎么选：本镜要锁角色/场景/道具，或要跟上一段音频 → `ref2va`。本镜不要参考图、不要音频、只要接着上一镜画面演 → `fl2va`。首镜没有上一镜尾帧，不能用 `fl2va`。

先看本镜相对上一镜是不是连续。只有 `连续镜头` 才抽尾帧、对照上一镜 prompt 看停在哪、再微调本镜 prompt。`切分镜头` 跳过这三步，直接用本镜分镜里的 prompt 出画。

`连续镜头` 且走 `ref2va` 时，生成前必须先看尾帧，再微调旧 prompt：

1. 对上一镜成片 `extract-video-frame` 抽尾帧。
2. 把上一镜实际用来生成视频的 prompt 和这张尾帧一起交给 `vision-understanding`，对照提示词看最后一幕停在了哪：人物在画面哪、朝向、景别、手势停在哪、背景怎么切、空间关系、光线从哪来。
3. 拿本镜分镜里的旧 prompt 来微调，不要另起一套：补上从哪个姿态/机位接上、剧情怎么往下演、如何不和尾帧打架。`reference_paths` 先放上一镜尾帧，再放角色/场景/道具；prompt 里写成[图1]作为首帧，其余参考按实际传入顺序接着编号。
4. 再调用 `video-gen`，使用微调后的 prompt，把尾帧和本镜资产一起传入。

`切分镜头` 不要抽上一镜尾帧，也不要对照尾帧改 prompt。传入本镜角色/场景/道具后，直接用本镜分镜里的 prompt 调用 `video-gen`。

**第 n+1 段若走 `ref2va`，无论连续还是切分，都用 `split-audio` 拆出第 n 段音频作为参考**，并在 prompt 里写明：参考[音频1]的音色、背景音乐，保持音频元素高度一致、剧情连贯；禁止重复音频里已经说过的内容和背景音乐。不要传入全部历史音频。

`fl2va` 只传那一张尾帧，prompt 写从这张图接着怎么动、这段演什么即可。不要把 `split-audio` 或其他参考图塞进 `fl2va`。

单段超时设得足够长（建议不少于 30 分钟）。每段生成后抽尾帧并挂上。用 `vision-understanding` 检查人设、场景、剧情是否符合；不合格重生当前段。通过后 `record_media` 挂到该镜头。

### 步骤5：合并与导出

前置检查：全部片段已生成。有缺失立刻返回步骤4。

1. `merge-video` 按镜头顺序合并，保证衔接流畅。
2. `set_deliverable` 登记成片。
3. 最终检查：角色外观和声音全片一致、场景不跳变、情节无断层、成片真实存在。缺文件或检查不过，不得对用户说已经做完。

## 硬规则

1. 元素一致性是核心。同一角色、场景、道具在不同片段必须保持一致，不得人设崩坏、场景突变。
2. 剧情必须连贯，符合逻辑，无叙事断层。
3. 每个片段时长不超过 `video-gen` 单次上限。
4. `ref2va` 无记忆，必须显式传入参考图和参考音频，并在 prompt 里说明如何使用它们。前后两镜连续时，生成前必须对照上一镜生成 prompt 看尾帧停在哪，微调本镜旧 prompt 后再生成；`reference_paths` 必须带上上一镜尾帧，并写成作为首帧。`切分镜头` 不看上一镜尾帧，也不传上一镜尾帧。
5. 不要用 `fl2va` 代替本该传入的角色、场景、道具资产。只有本镜明确只要画面强制连贯、且不需要参考图和音频时才用 `fl2va`。
6. 第 n+1 段若走 `ref2va`，必须使用第 n 段拆出的音频作参考，但不得传入全部历史音频。`fl2va` 不传参考音频。
7. 成片必须 `set_deliverable`。
